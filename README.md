# Rho Chi Omega — "Pearls & Ivy" Concept Redesign

A one-page concept redesign for the **Rho Chi Omega Chapter of Alpha Kappa Alpha Sorority, Incorporated®**, built to show the chapter what a sleeker, more modern site could look like.

**This is a concept mockup only.** It is not affiliated with, and does not replace, the chapter's live site at [aka-rco.org](https://www.aka-rco.org/). No changes were made there — this is a standalone demo for internal discussion.

## What's here

- A single scrolling page (hero → president's welcome → chapter story → program targets → leadership → foundation → gallery → get involved)
- A full-screen overlay menu, inspired by the international AKA site ([aka1908.com](https://aka1908.com))
- "Pop-out" modal windows for expanded detail — program targets, officer cards, the charter member roster, and the president's full welcome letter — so the page stays short while the detail is still one click away
- A deep emerald green + rose pink palette with champagne gold accents, built around the chapter's own colors and the "Cultured Pearls" / ivy leaf imagery from its founding story
- All chapter content (history, officers, program targets) pulled directly from the chapter's own public pages

## Photos

Real chapter photos throughout, supplied by the chapter: the full-chapter hero photo, a professional headshot of President Tiffany Richardson, the 1989 charter members photo, the AKA crest and Emerald Foundation logo, all 18 executive board members' headshots (pop-out "Meet the Full Board"), a 6-photo gallery carousel, and both Upcoming Events flyers (Emerald Fundraiser, 35th Angel Pageant).

## What's placeholder

- Officer bio text inside the board pop-out is a placeholder — ready for each officer's own words
- "Member Login" links to `#` — wire it up to the chapter's real member portal when ready

## Running locally

No build step — just serve the folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
